How this was built

Methodology & honest limitations

Transcripts could not be downloaded verbatim. This site was built inside a sandbox whose network policy blocks youtube.com and third-party transcript/recap sites (every request returns HTTP 403 through an allowlist proxy). So instead of extracting caption files, each talk's conclusions were reconstructed from web search over Anthropic's own session pages (claude.com), official blog recaps, and independent reporting/live-blogs. Treat the per-talk bullets as faithful summaries, not word-for-word quotes — and follow each card's "Sources" for the originals.

Scope & inclusion

  • Official channels only: @anthropic-ai and @claude.
  • Window: ~Apr 15 → May 27, 2026 (six weeks).
  • Topic filter: must be about Claude Code / agentic coding.
  • Third-party tutorials and reaction videos were excluded.

What's most reliable

  • Talk titles, speakers, dates, and session URLs (from claude.com).
  • Headline announcements (Managed Agents, Dreaming/Outcomes/Orchestration).
  • Cross-checked advice that appears in multiple sources.

Run it locally

  • It's a static site — open index.html directly, or
  • python3 -m http.server 8000 then visit localhost:8000.
  • No build step, no dependencies, works offline.
